# Wedding Invitation Website

A single-page wedding invite: you tap a wax-sealed envelope to open it, then get falling petals, a countdown, the couple, event cards (Haldi / Mehendi / Sangeet / Wedding / Reception), a gallery, a venue map and an RSVP form that sends the reply on WhatsApp.

## Customise
1. Open `index.html` and edit the `WEDDING` object near the bottom (names, dates, events, venue, WhatsApp number, music).
2. Put photos in `images/`: `hero.jpg`, `groom.jpg`, `bride.jpg`, and gallery photos `1.jpg` … `6.jpg`.
3. Optional: add a song (e.g. `music/song.mp3`) and set `music` in the config.

## Publish
Enable GitHub Pages (Settings → Pages → deploy from branch, root folder) or drag the folder onto Netlify/Vercel.
